# Qwen Code (`qwen-code`) - Complete Feature Reference

Official Documentation: [Qwen Code Documentation](https://qwenlm.github.io/qwen-code-docs/)

| Feature / Command | Documentation Link | How It Works & Configuration | How to Use (Syntax / Config) | Concrete Real-World Use Case |
| :--- | :--- | :--- | :--- | :--- |
| **Agent Skills (`SKILL.md`)** | [Agent Skills](https://qwenlm.github.io/qwen-code-docs/en/users/features/skills/) | Modular capability packages with instructions and scripts in `SKILL.md`; auto-invoked or via `/<skill>`. | `.qwen/skills/audit/SKILL.md` or `/<skill>` | Packaging complex domain runbooks (smart contract audits, DB migrations). |
| **`/learn`** | [Skill Synthesis](https://qwenlm.github.io/qwen-code-docs/en/users/features/skills/#skill-synthesis) | Automatically synthesizes the current conversation's successful workflow into a permanent Agent Skill. | `/learn` | Turning a hard-won debugging workflow into a permanent reusable capability. |
| **Path-Conditional Rules** | [Conditional Rules](https://qwenlm.github.io/qwen-code-docs/en/users/features/rules/) | Markdown rules in `.qwen/rules/` with `paths: [...]` loaded into context *only* when matching files are edited. | `--- \n paths: ['src/**/*.tsx'] \n ---` | Slashing prompt token costs by loading UI guidelines only when editing UI code. |
| **`QWEN.md` Hierarchy** | [Project Context](https://qwenlm.github.io/qwen-code-docs/en/users/features/memory/#qwen-md) | Multi-tier briefings: `~/.qwen/QWEN.md` (user), `QWEN.md` (team), `.qwen/QWEN.local.md` (personal). | `/init` to generate baseline `QWEN.md` | Providing permanent context on build commands and coding standards. |
| **Two-Tier Auto-Memory** | [Auto-Memory Engine](https://qwenlm.github.io/qwen-code-docs/en/users/features/memory/) | Persistent memory observing user preferences and repo facts. Commands: `/remember`, `/forget`, `/dream`. | `/memory`; `/remember <fact>`; `/dream` | Retaining knowledge across sessions (e.g. "Vitest preferred over Jest") automatically. |
| **Headless Mode (`-p`, `--continue`)** | [Headless Execution](https://qwenlm.github.io/qwen-code-docs/en/users/reference/cli-options/#headless) | Non-interactive CLI runner supporting prompt arguments, stdin pipes, and stream resumption. | `qwen -p "Review src/api.ts"` | Powering unattended GitHub Actions CI/CD pipelines for automated PR reviews and linters. |
| **20+ Lifecycle Hooks** | [Event Hooks](https://qwenlm.github.io/qwen-code-docs/en/users/features/hooks/) | Deterministic shell hooks on events (`PreToolUse`, `PostToolUse`, `UserPromptSubmit`, `SessionStart`). | In `.qwen/settings.json`: `"hooks": {...}` | Enforcing security barriers, blocking dangerous bash commands, and auto-formatting code. |
| **Scheduled Tasks (`/loop`)** | [Cron Loops](https://qwenlm.github.io/qwen-code-docs/en/users/features/channels/overview/#scheduled-tasks) | Built-in cron task runner scheduling recurring prompts at natural language intervals (`5m`, `1h`). | `/loop 5m check if deployment finished` | Babysitting cloud deployments or polling GitHub PR status while continuing to code. |
| **8 Multi-Channel Bridges** | [Enterprise Channels](https://qwenlm.github.io/qwen-code-docs/en/users/features/channels/overview/) | Direct bridges to Telegram, WeChat, DingTalk, WeCom, Feishu (Lark), QQ Bot, GitHub, GitLab. | Authenticate via DM Pairing codes | Controlling your local dev agent remotely from your mobile phone while commuting. |
| **Native LSP Integration** | [Language Server Protocol](https://qwenlm.github.io/qwen-code-docs/en/users/features/rules/#lsp) | Built-in LSP client communicating directly with daemons (`gopls`, `pyright`, `tsserver`, `rust-analyzer`). | Configure under `lsp` in settings | Catching syntax errors, missing imports, and type errors before running compilers. |
| **Agent Arena (`/arena`)** | [Model Benchmarking](https://qwenlm.github.io/qwen-code-docs/en/users/features/skills/#agent-arena) | Multi-model evaluation running the same prompt side-by-side to benchmark code accuracy and speed. | `/arena` | Benchmarking local open-source models against cloud frontier models. |
| **Git Worktree Isolation** | [Worktrees](https://qwenlm.github.io/qwen-code-docs/en/users/reference/cli-options/#worktree) | Provisions isolated Git worktrees for experimental agent modifications, keeping main tree clean. | Configure `worktree: true` in settings | Letting the agent test an aggressive architectural rewrite without dirtying local unstaged edits. |
| **Daemon Mode (`qwen-serve`)** | [REST API Daemon](https://qwenlm.github.io/qwen-code-docs/en/users/reference/cli-options/#daemon) | Runs Qwen Code as a persistent background server exposing HTTP REST endpoints for integrations. | `qwen-serve --port 8080` | Turning your dev machine into a private, self-hosted AI coding API. |
| **Approval Mode Cycling** | [Autonomy Cycling](https://qwenlm.github.io/qwen-code-docs/en/users/reference/keyboard-shortcuts/) | Cycles presets: `plan`, `default`, `auto-edit`, `auto`, `yolo`. | Press `Shift+Tab` (or `Tab` on Windows) | Switching to `auto-edit` for rapid boilerplate and back to `plan` for critical security logic. |
| **Keyboard Ergonomics** | [Shortcuts Reference](https://qwenlm.github.io/qwen-code-docs/en/users/reference/keyboard-shortcuts/) | Shortcuts: `Esc` double-tap (rewind), `Ctrl+C` (cancel/exit), `Ctrl+O`/`Alt+T` (thinking), `Ctrl+S` (stash). | Built into CLI TUI | Maximizing developer speed without taking hands off the keyboard. |
