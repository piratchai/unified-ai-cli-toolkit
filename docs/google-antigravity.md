# Google Antigravity CLI (`agy`) - Complete Feature Reference

Official Documentation: [Google Antigravity Docs](https://antigravity.google/docs/)

| Feature / Command | Documentation Link | How It Works & Configuration | How to Use (Syntax / Config) | Concrete Real-World Use Case |
| :--- | :--- | :--- | :--- | :--- |
| **`/boost <task>`** | [Reasoning Modes](https://antigravity.google/docs/cli/reference/#boost) | Multi-agent deep reasoning with tree-of-thought exploration, iterative hypothesis testing, and self-verification passes. | `/boost Fix intermittent deadlock in connection_pool.go` | Diagnosing elusive race conditions, memory leaks, and distributed consensus edge cases. |
| **`/teamwork-preview <task>`** | [Multi-Agent Swarm](https://antigravity.google/docs/subagents/#teamwork) | Spawns a collaborative multi-agent swarm: Lead Orchestrator delegates tasks with adversarial verification gates. | `/teamwork-preview Migrate frontend from Vue 2 to Svelte 5` | Massive framework migrations spanning 50+ files with parallel specialized agents. |
| **`/plan <task>`** | [Planning Mode](https://antigravity.google/docs/cli/reference/#plan) | Formulates an architectural design specification artifact (`<plan>.md`) with verification steps before editing code. | `/plan Refactor authentication service to OAuth2 PKCE` | Architectural RFC design reviews where teams require consensus before modifying sensitive code. |
| **`/planning`** | [Disciplined Planning](https://antigravity.google/docs/cli/reference/#planning) | Toggles persistent multi-turn planning mode on/off across every turn. | `/planning` (toggles on/off) | Enforcing structured roadmap generation for complex refactoring initiatives. |
| **`/agents` Dashboard** | [Agent Supervisor](https://antigravity.google/docs/subagents/#dashboard) | Interactive TUI dashboard displaying subagents, states (`running`, `idle`, `waiting_for_input`), and approval queues. | Type `/agents`; Enter opens transcript; `Alt+J` navigates approvals | Monitoring parallel background unit test runs while continuing primary conversation. |
| **Code Search Engine** | [AST Graph Index](https://antigravity.google/docs/cli/reference/#codesearch) | Semantic and structural AST graph search (`search_graph`, `trace_path`, `get_code_snippet`) without regex grep. | Autonomous tool calls by agent | Tracing end-to-end data flow from an API route down to database ORM models in monorepos. |
| **`/diff`** | [Diff Viewer](https://antigravity.google/docs/cli/reference/#diff) | Built-in interactive side-by-side and unified git diff viewer. | `/diff` | Line-by-line verification of regex refactors or SQL migrations before writing to disk. |
| **`/permissions`** | [Security Sandbox](https://antigravity.google/docs/sandbox/#permissions) | Autonomy control levels: `request-review`, `proceed-in-sandbox`, `always-proceed`, `strict`. | `/permissions` or in `settings.json`: `"toolPermission": "request-review"` | Locking agent to read-only during security audits, or enabling full autonomy in CI/CD containers. |
| **`/resume`** | [Session Manager](https://antigravity.google/docs/cli/reference/#resume) | Fuzzy session picker inspecting conversation logs to resume historic threads. | `/resume` | Continuing an ongoing debugging session started yesterday after rebooting workstation. |
| **`/rewind`** | [Checkpoint Rollback](https://antigravity.google/docs/cli/reference/#rewind) | Checkpoint rollback engine reverting conversation history and uncommitted file edits. | `/rewind` | Instantly recovering when an experimental implementation breaks the build. |
| **`/statusline`** | [Status Telemetry](https://antigravity.google/docs/cli/reference/#statusline) | Status bar pipe streaming live JSON metadata into external shell scripts or tmux status. | `/statusline` or in `settings.json`: `"statusLine": {"command": "./bar.sh"}` | Building custom tmux or Starship status bars showing agent thinking state and tokens. |
| **`/tasks`** | [Task Supervisor](https://antigravity.google/docs/cli/reference/#tasks) | Background task manager monitoring, retrieving logs, and killing background commands. | `/tasks` | Supervising persistent background servers (`vite dev`, `docker compose`) launched by agent. |
| **`/voice` (`F5`)** | [Voice Dictation](https://antigravity.google/docs/cli/reference/#voice) | Integrated voice transcription engine converting microphone audio directly into prompt text. | Press `F5` or type `/voice` | Hands-free dictation of architectural requirements while reviewing diffs. |
| **`/remote-control`** | [Remote Pairing](https://antigravity.google/docs/cli/reference/#remote-control) | Secure web pairing endpoint generating QR code/link to drive CLI from mobile devices. | `/remote-control` | Monitoring long-running builds and approving tool calls from a smartphone while away from desk. |
| **`/plugin`** | [Plugin Registry](https://antigravity.google/docs/cli/reference/#plugin) | Interactive plugin manager for installing, enabling, and uninstalling packaged toolkits. | `/plugin install firebase@marketplace` | Distributing company-wide linting, security, and cloud deployment tools across developers. |
| **`/add-dir <path>`** | [Multi-Root Workspaces](https://antigravity.google/docs/cli/reference/#add-dir) | Adds an external folder path to workspace context without changing Git root. | `/add-dir ../shared-libs/auth-core` | Working on monorepos where the primary project imports types from adjacent directories. |
| **`/artifact` (`Ctrl+R`)** | [Artifact Review](https://antigravity.google/docs/cli/reference/#artifact) | Opens dedicated Artifact Review drawer to inspect generated design docs and diffs. | `/artifact` or `Ctrl+R` | Reviewing architectural design documents and test plans before approving implementation. |
| **`/btw <query>`** | [Background Query](https://antigravity.google/docs/cli/reference/#btw) | Submits a quick side question without cluttering the main conversation history. | `/btw What is RFC 7235 status 401?` | Looking up syntax, standards, or error codes without interrupting a multi-step task. |
| **Native Sandboxing** | [OS Sandboxing](https://antigravity.google/docs/sandbox/) | Native OS container containment (AppContainer / namespaces / Seatbelt). | Enabled by default for all non-bypassed commands | Preventing accidental host disk damage or unauthorized external network connections. |
| **Lifecycle Hooks** | [Event Hooks](https://antigravity.google/docs/hooks/) | Deterministic shell hooks on events: `PreToolUse`, `PostToolUse`, `PreInvocation`, `PostInvocation`, `Stop`. | In `settings.json`: `"hooks": {"PreToolUse": [...]}` | Automatically formatting files after edits or blocking destructive shell commands. |
| **Sidecars** | [Persistent Sidecars](https://antigravity.google/docs/sidecars/) | Long-running background service daemons bound to the agent session (`sidecar.json`). | Declare in `sidecar.json` | Providing mock API servers or test databases for agent integration tests. |
| **Agent Skills** | [Skills System](https://antigravity.google/docs/skills/) | Progressive-disclosure capability directories with `SKILL.md`, scripts, and schemas. | `.gemini/skills/<name>/SKILL.md` | Equipping the agent with specialized domain knowledge (e.g. database migration scripts). |
