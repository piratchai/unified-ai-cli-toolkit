# Pi CLI (`pi`) - Complete Feature Reference

Official Documentation: [Pi CLI Documentation](https://pi.dev/docs/latest/cli)

| Feature / Command | Documentation Link | How It Works & Configuration | How to Use (Syntax / Config) | Concrete Real-World Use Case |
| :--- | :--- | :--- | :--- | :--- |
| **8 Primitive Tools** | [Core Tools](https://pi.dev/docs/latest/tools) | Minimalist tool surface area: `read`, `bash`, `powershell`, `edit`, `write`, `grep`, `find`, `ls`. | Invoked autonomously by agent | Deterministic, ultra-fast file operations with zero prompt bloat. |
| **`codemode` Sandbox** | [QuickJS Sandbox](https://pi.dev/docs/latest/extensions/#codemode) | Embedded QuickJS JS engine running scripts locally to batch multiple operations in one LLM turn. | Built into agent execution loop | Refactoring dozens of source files simultaneously without paying multiple API round-trips. |
| **`tool_search`** | [Lazy Loading](https://pi.dev/docs/latest/tools/#dynamic-search) | Dynamically indexes and searches tool schemas on-demand rather than loading all up front. | Autonomous tool search | Connecting 30+ MCP servers while keeping system prompt token costs near zero. |
| **`pi --print` (`-p`)** | [Scripting Mode](https://pi.dev/docs/latest/cli/#non-interactive) | Headless non-interactive execution mode outputting plain text directly to standard out. | `pi -p "Explain src/main.rs" > doc.txt` | Chaining Pi inside bash scripts, unix pipes, and automated build checks. |
| **`pi --mode json`** | [Stream Events](https://pi.dev/docs/latest/cli/#json-streaming) | Streams real-time conversation and tool execution events as structured JSON objects. | `pi --mode json "Refactor api.ts"` | Embedding Pi into custom IDE plugins, desktop GUIs, or internal web dashboards. |
| **`pi --mode rpc`** | [JSON-RPC Protocol](https://pi.dev/docs/latest/cli/#json-rpc) | Full-duplex JSON-RPC 2.0 interface communicating over standard I/O. | `pi --mode rpc` | Driving Pi programmatically from external processes, test runners, or daemon workers. |
| **`pi install / update`** | [Package Manager](https://pi.dev/docs/latest/extensions/#packages) | Integrated package manager for extensions, themes, and prompt toolkits directly from Git. | `pi install github.com/user/pi-tools` | Installing and sharing community extensions and team automation tools. |
| **`pi auth`** | [Credential Vault](https://pi.dev/docs/latest/cli/#authentication) | Local encrypted keyring managing provider API tokens for Anthropic, OpenAI, and local endpoints. | `pi auth login` | Secure credential storage without leaking plain text keys in committed project repositories. |
| **`pi mcp`** | [MCP Client](https://pi.dev/docs/latest/tools/#mcp) | Command line interface to add, list, test, and remove Model Context Protocol servers. | `pi mcp add pg ./mcp-postgres.js` | Connecting external database query tools, browser automations, or GitHub MCP servers. |
| **`/thinking [budget]`** | [Reasoning Tokens](https://pi.dev/docs/latest/slash-commands/#thinking) | Configures reasoning token budget for extended thinking models (e.g. Claude 3.7 Sonnet). | `/thinking 4096` | Giving the model extra reasoning depth for complex algorithmic challenges. |
| **`/scoped-models`** | [Model Routing](https://pi.dev/docs/latest/settings/#scoped-models) | Routes cheap fast models to shell/file tasks and frontier reasoning models to system design. | Configured in settings or `/scoped-models` | Slashing API token costs while preserving top-tier code generation quality. |
| **`/llama`** | [Local Inference](https://pi.dev/docs/latest/cli/#llama-cpp) | Native integration with local `llama.cpp` inference engines. | `/llama start --model mistral.gguf` | Working completely offline in air-gapped environments without external network access. |
| **`/tree`** | [Session Branching](https://pi.dev/docs/latest/slash-commands/#tree) | Interactive visual conversation tree showing all historical branching nodes. | `/tree` | Comparing and switching between multiple divergent debugging approaches. |
| **`/fork` & `/clone`** | [Branch Management](https://pi.dev/docs/latest/slash-commands/#fork) | Forks conversation at the current turn into a new child branch, or clones session state. | `/fork` or `/clone` | Testing speculative code changes without corrupting the primary working conversation. |
| **Compaction Engine** | [Context Compaction](https://pi.dev/docs/latest/compaction) | Automatic token pruner that summarizes older turns while preserving recent context (`reserveTokens`). | Automatic or triggered via `/compact` | Keeping multi-hour sessions alive without running into context overflow limits. |
| **TypeScript Extensions** | [Extension API](https://pi.dev/docs/latest/extensions) | Write custom extensions in pure TypeScript executed directly by Pi without compile step. | `~/.pi/extensions/*.ts` | Building custom enterprise linters, compliance checks, or custom slash commands. |
