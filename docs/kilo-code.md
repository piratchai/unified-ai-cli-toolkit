# Kilo Code (`kilocode`) - Complete Feature Reference

Official Documentation: [Kilo Code CLI Docs](https://kilo.ai/docs/code-with-ai/platforms/cli)

| Feature / Command | Documentation Link | How It Works & Configuration | How to Use (Syntax / Config) | Concrete Real-World Use Case |
| :--- | :--- | :--- | :--- | :--- |
| **Headless `kilo run`** | [Headless Mode](https://kilo.ai/docs/code-with-ai/platforms/cli#headless-mode) | Non-interactive command runner supporting stdin pipe and streaming JSON output. | `git diff | kilo run "Review changes"` | Automated GitHub Actions CI/CD workflows and automated commit authoring. |
| **`kilo attach <id>`** | [Session Attach](https://kilo.ai/docs/code-with-ai/platforms/cli#attach) | Attaches local terminal to an existing ongoing background Kilo session. | `kilo attach sess_8f29d` | Taking control of a long-running background refactoring task started earlier. |
| **`kilo serve` & `daemon`** | [Daemon Server](https://kilo.ai/docs/code-with-ai/platforms/cli#daemon) | Runs Kilo as a persistent background daemon or Agent Client Protocol (ACP) server. | `kilo serve --port 5000` | Integrating Kilo Code with external developer tools, web frontends, and IDE plugins. |
| **`kilo auth`** | [Unified Gateway](https://kilo.ai/docs/code-with-ai/platforms/cli#auth) | Unified credential manager supporting direct provider keys and Kilo Gateway (500+ models). | `kilo auth login` or `/connect` | Eliminating API key sprawl by managing all frontier models through one secure vault. |
| **`kilo roll-call <filter>`** | [Model Diagnostics](https://kilo.ai/docs/code-with-ai/platforms/cli#roll-call) | Benchmarking tool that batch-tests models matching regex for network connectivity and latency. | `kilo roll-call "claude.*sonnet"` | Testing fallback provider latency and availability before starting a high-speed coding session. |
| **`kilo export / import`** | [Session Transcripts](https://kilo.ai/docs/code-with-ai/platforms/cli#export-import) | Serializes complete conversation trajectories to and from JSON files or URLs. | `kilo export session.json` | Sharing complex debugging trajectories with coworkers or saving compliance audit records. |
| **`kilo pr review`** | [PR Integration](https://kilo.ai/docs/code-with-ai/platforms/cli#github-pr) | Integrated GitHub Pull Request manager reviewing PR diffs and submitting comments directly. | `kilo pr review 142` | Reviewing and commenting on teammate pull requests directly from the terminal. |
| **`code` Agent** | [Code Persona](https://kilo.ai/docs/code-with-ai/agents/using-agents#code-agent) | Full software engineering agent with unrestricted file editing and terminal command access. | Default agent (`Ctrl+.` to cycle) | Day-to-day coding, feature implementation, and bug fixing. |
| **`ask` Agent** | [Ask Persona](https://kilo.ai/docs/code-with-ai/agents/using-agents#ask-agent) | Strictly read-only agent persona. File writes and destructive shell commands are blocked. | Switch via `/agents` or `Ctrl+.` | Exploring and querying unfamiliar codebases safely without risking accidental edits. |
| **`plan` Agent** | [Plan Persona](https://kilo.ai/docs/code-with-ai/agents/using-agents#plan-agent) | Technical lead persona. Read-only on source code; write access restricted to `.kilo/plans/*.md`. | Switch via `/agents` or `Ctrl+.` | Designing technical blueprints and implementation plans before writing code. |
| **`debug` Agent** | [Debug Persona](https://kilo.ai/docs/code-with-ai/agents/using-agents#debug-agent) | Troubleshooting persona configured to reproduce bugs, inspect stack traces, and isolate issues. | Switch via `/agents` or `Ctrl+.` | Hunting down elusive runtime bugs, null pointer exceptions, and flaky unit tests. |
| **`/resume-claude [uuid]`** | [Claude Importer](https://kilo.ai/docs/code-with-ai/platforms/cli#resume-claude) | Native transcript importer reading and resuming historical sessions from Claude Code. | Start `/new`, run `/resume-claude` | Seamlessly migrating an ongoing Claude Code terminal session into Kilo without losing context. |
| **`/resume-codex [uuid]`** | [Codex Importer](https://kilo.ai/docs/code-with-ai/platforms/cli#resume-codex) | Native transcript importer parsing and resuming historical sessions from OpenAI Codex CLI. | Start `/new`, run `/resume-codex` | Transitioning an OpenAI Codex terminal session into Kilo to leverage alternative models. |
| **`/move`** | [Directory Relocate](https://kilo.ai/docs/code-with-ai/platforms/cli#move) | Relocates active conversation thread and workspace context to a different project directory. | `/move ~/code/backend-service` | Following bugs that span across frontend and backend microservice repositories. |
| **`/goal [objective]`** | [Goal Tracker](https://kilo.ai/docs/code-with-ai/platforms/cli#goal) | Persistent goal tracker anchoring the agent to a specific objective across multiple turns. | `/goal Implement OAuth2 PKCE login` | Preventing goal drift during long-running, multi-turn feature development sprints. |
| **`/caffeinate`** | [Keep-Awake Toggle](https://kilo.ai/docs/code-with-ai/platforms/cli#caffeinate) | Operating system keep-awake toggle preventing workstation sleep while Kilo is working. | `/caffeinate` | Running autonomous overnight test suites without sleep interruptions. |
| **Smart Mentions** | [Context Mentions](https://kilo.ai/docs/code-with-ai/platforms/cli#mentions) | Prompt syntax allowing inline injection of file contents or recent terminal output (`@file`, `@terminal`). | `Explain @file:src/auth.ts and @terminal` | Grounding agent in specific files or compiler errors without manual copy-pasting. |
| **Custom Rules** | [Project Rules](https://kilo.ai/docs/code-with-ai/rules) | Project-specific guidelines and constraints loaded automatically from `.kilocode/rules/*.md`. | Save in `.kilocode/rules/style.md` | Mandating project conventions (e.g. "always use Tailwind CSS, never raw CSS"). |
