# Universal Semantic Commit

Generates semantic commit messages following Conventional Commits 1.0.0 (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`).

## Usage Across CLIs
- **AGY**: `/voice "Generate conventional commit"`
- **Pi**: `pi -p "Generate commit message for git diff"`
- **OpenCode**: `/commit-push`
- **Kilo**: Use built-in commit generator or prompt `@file @terminal`
- **Qwen**: `git diff | qwen -p "Generate conventional commit"`
